# Data Structure

Dados podem ser organizados de diferentes maneiras, o modelo lógico ou metamatico de organizar dados é chamado de data structures (estruturas de dados). A escolha de um data structure particular, depende de algumas considerações:

1. Deve ser possivel representar a relação do dado no mundo real
2. Deve ser simples o suficiente para que isso possa ser processado eficientemente como e quando necessario



<note>

**O estudo de estruturas de dados inclui:**

- Descrição lógica da data structure
- Implementação da data structure
- Analise quantidade da estrutura de dados. Essa analise inclui determinação do montande de memoria necessaria para armazenar a data structure, também chamada de _space complexity_, e o tempo requerido para processar isso, também chamado de _time complexity_

</note>


#### Time complexity

Essa a mensuração da estimativa do **tempo de execução de um algoritmo em termos do tamanho dos dados de entrada**. Para esse proposito uma notação popular é usada que é chamada de: big O


#### Space Complexity

Essa mensuração é usada para definir o espaço extra consumido pelo algoritmo exceto a entrada de dados. Asim também temos a notação big O sendo usada
